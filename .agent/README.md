# .agent/ — Disposable, Session-Scoped Agent Notes Only

This is **not** project knowledge and is never cited as evidence of what's true about V.I.S.I.O.N.
For that, see [`docs/`](../docs/README.md) — the actual second brain.

What belongs here (safe to be messy, wrong, or stale; none of it is durable):
- A raw, chronological per-session working log (e.g. `.agent/memory/session_log.md`), if one is
  kept.
- Local command references / per-developer tool cheat-sheets (e.g. `.agent/skills/local_tools.md`)
  — operational config for running an agent tool in this specific environment, not project facts.

Any durable, reusable conclusion reached during a session gets promoted into `docs/memory/`
instead of staying here. This folder previously held `domains/docs/` and `memory/` content that
was actually durable project knowledge, just filed under the wrong convention — all of it has
been moved into `docs/domains/` and `docs/memory/` respectively.
